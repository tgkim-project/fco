# fco 구현 계획

서버 없는 FC온라인 도우미 앱. 웹(PWA)으로 시작해 Capacitor로 Play 스토어 / App Store에 출시한다.

> 피온북 같은 기존 앱과 기능만 비슷하며, 이름·디자인·로고는 자체 제작한다. 넥슨과 무관한 비공식 앱이다.

## 요구사항

- **서버 없음**: 자체 백엔드/DB 없이 정적 파일 + 기기 저장소 + 외부 공개 API만 사용
- **API 키**: 사용자가 자기 NEXON Open API 키를 입력하고, 앱 안에 키 발급 가이드를 제공
- **스토어 출시**: 최종적으로 Google Play, App Store에 배포
- **MVP 기능**
  1. 전적 검색 — 닉네임 → 등급, 최근 경기, 경기 상세
  2. 선수 검색 — 이름/시즌 검색, 선수 이미지, 시즌 배지
  3. 스쿼드 메이커 — 포메이션 선택, 선수 배치, 기기 저장, URL 공유

## 기술 스택

| 항목 | 선택 | 이유 |
|---|---|---|
| 앱 | Vite + React + TypeScript | 가볍고 생태계가 넓음 |
| 라우팅 | React Router (HashRouter) | GitHub Pages와 Capacitor 모두에서 새로고침 404 없음 |
| 웹 배포 | PWA + GitHub Pages | 서버 없이 정적 호스팅 |
| 네이티브 | Capacitor | 같은 웹 코드로 Android/iOS 빌드, 네이티브 HTTP로 CORS 회피 |
| 데이터 | NEXON Open API (FC온라인) | 공식 전적·메타데이터 |
| 저장 | localStorage / IndexedDB, 앱에서는 보안 저장소 | 키·스쿼드·메타데이터 캐시 |
| 테스트 | Vitest + Testing Library | Vite와 설정 공유 |

## 단계

### 1단계: 프로젝트 뼈대 — 작음
- Vite + React + TS 초기화, ESLint, Vitest
- 라우팅: `/`, `/match`, `/players`, `/squad`, `/settings`, `/guide`
- PWA 설정(매니페스트, 서비스워커), GitHub Pages 배포 워크플로

### 2단계: API 키 설정과 가이드 — 작음
- 키가 없으면 첫 실행 시 키 등록 화면으로 안내
- 설정 화면: 키 입력·저장, "연결 테스트", 키 삭제
- `/guide` 키 발급 가이드 (스크린샷 포함)
  1. NEXON Open API(openapi.nexon.com)에 넥슨 계정으로 로그인
  2. 애플리케이션 등록 → 게임 "FC 온라인" 선택
  3. 발급된 키를 복사해 앱 설정에 붙여넣기
  4. FAQ: 키는 기기에만 저장되며 외부로 전송되지 않음 / 호출 한도 / 만료·재발급 시 대처
- ⚠️ 정확한 메뉴명·절차는 구현 시 실제 사이트를 확인해 맞춘다 (현재 미확인 초안)

### 3단계: API 연결 계층 — 중간
- 계정 ID(ouid) 조회, 기본 정보, 최고 등급, 경기 목록·상세
- 메타데이터(spid, seasonid, spposition) 로드 후 IndexedDB 캐시
- 웹은 `fetch`, 앱은 Capacitor HTTP를 쓰는 공통 클라이언트
- 오류 구분: 키 없음/잘못됨(→ 가이드), 호출 한도 초과(429), 닉네임 없음

### 4단계: 전적 검색 — 중간
- 닉네임 검색, 유저 요약, 경기 목록(무한 스크롤), 경기 상세(스코어·슈팅·점유율·출전 선수)
- 최근 검색 기록

### 5단계: 선수 검색 — 중간
- 메타데이터 기반 로컬 검색 (한글 초성 검색, 시즌 필터)
- 선수 이미지와 대체 이미지

### 6단계: 스쿼드 메이커 — 큼
- 포메이션 프리셋, 드래그 앤 드롭 배치
- 여러 스쿼드 저장, URL로 공유(스쿼드를 압축해 주소에 담음)

### 7단계: 앱 패키징 — 중간
- Capacitor Android/iOS 프로젝트 생성
- 앱 아이콘, 스플래시, 뒤로가기 처리, 보안 저장소 플러그인
- Android 서명 키, AAB 빌드, 실기기 테스트

### 8단계: 스토어 출시 준비 — 중간
- 개인정보처리방침 페이지(수집 정보 없음, 키는 기기에만 저장)를 GitHub Pages에 게시
- 스토어 설명, 스크린샷, "넥슨과 무관한 비공식 앱" 고지
- Play 스토어 내부 테스트 → 정식 출시 → App Store

## 확인된 사실 (2026-11-23)

- 키 전송: `x-nxopen-api-key` 헤더, 서버 `https://open.api.nexon.com`
- 브라우저(localhost)에서 직접 호출 가능 — CORS 허용 확인
- 잘못된 키 → `400 OPENAPI00005`, 파라미터 누락 → `400 OPENAPI00004`
- 메타데이터(`/static/fconline/meta/*.json`)는 키 없이 조회 가능
- 개발 단계 키 한도: 초당 5건, 하루 1,000건
- **seasonid 메타데이터 API는 2026-11-19 종료 → season / class 메타데이터 API로 대체** (3·5단계에 반영)
- 약관: 키 공유 금지(제5조①), 앱에 "Data based on NEXON Open API" 표기(제6조④), 회사 동의 없는 상업적 이용 금지(제6조⑥) → 8단계 전 광고·유료화 여부 결정 필요
- 데이터는 매시 정각, 두 시간 전까지 반영
- API 명세 원본: `openapi.nexon.com/static/api/fconline/{2,3,4,5,6}_*.yaml` (2 유저, 3 매치, 4 랭커, 5 메타데이터, 6 이미지)
- `season.json`은 공식경기 랭크 시즌(예: 202606)이고, 선수 카드 시즌은 `class.json` (spid 앞 3자리 = class, 뒤 6자리 = pid)
- `spid.json`은 약 9.3만 건·6MB → IndexedDB 캐시(첫 로드 약 0.2초, 이후 약 0.05초, 로컬 측정)
- 선수 이미지: `fco.dn.nexoncdn.co.kr/live/externalAssets/common/players/p{spid}.png`, 없으면(403) `p{pid}.png`
- 매치 목록 API는 매치 ID 문자열 배열을 돌려준다. matchtype: 30 리그 친선, 40 클래식 1on1, 50 공식경기, 52 감독모드, 60 공식 친선, 204/214/224/234 볼타
