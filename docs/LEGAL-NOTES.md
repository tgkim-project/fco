# 법적 검토 메모: FC온라인 데이터센터 크롤링

- 조사일: 2026-11-24
- 질문: 공식 홈페이지 데이터센터(https://fconline.nexon.com/datacenter)의 선수 능력치·급여·팀 컬러를 크롤링해, 서버 DB 없이 앱 내부 DB로 쓸 수 있는가?
- 결론: **하지 않는다.** NEXON Open API 범위 안에서만 만든다. (넥슨 문의도 하지 않기로 함)

> 변호사의 법률 의견이 아니라 약관·법 조문·판례·스토어 정책을 조사한 기록이다. [2차 자료]는 언론·요약 사이트로만 확인한 것, [미확인]은 원문을 찾지 못한 것이다.

## 검토한 방법

| | 방법 |
|---|---|
| A | 개발 PC에서 미리 수집해 앱에 넣거나 정적 JSON으로 배포 → 앱이 기기 DB에 저장 |
| B | 앱이 사용자 기기에서 직접 홈페이지를 수집해 기기 DB에 저장 |

- 제11조 제1항 제15호: 동의 없는 영리·영업·광고 목적 이용 금지
- 제11조 제1항 제8호: 회사·제3자 지식재산권 침해 금지
- 제17조 제4항: 회사 저작물을 사전승낙 없이 복제·전송·배포해 영리 목적 이용 금지

## 2. 저작권법 – 데이터베이스제작자의 권리

- 제2조 제19·20호: 데이터베이스와 제작자(상당한 투자를 한 자) 정의
- 제93조: 전부 또는 상당한 부분의 복제·배포·전송권. 반복적·체계적으로 일부를 복제해 같은 결과가 되면 상당한 부분 복제로 본다
- 제94조: 비영리 교육·학술·연구, 시사보도 목적 예외
- 제95조: 보호기간 5년 (갱신 투자 시 새로 기산)
- 제136조 제3항 제3호: 3년 이하 징역 또는 3천만원 이하 벌금
- 친고죄 여부 [미확인]

## 3. 부정경쟁방지법

- 제2조 제1호 (카)목 데이터 부정사용: 보호 데이터는 "업으로서 특정인 또는 특정 다수에게 제공되는" 데이터 → 누구나 보는 공개 데이터는 원칙적으로 보호 대상이 아니라는 해설 [2차 자료]
- 제2조 제1호 (파)목 보충적 일반조항: 타인의 상당한 투자로 만든 성과를 "자신의 영업을 위하여" 무단 사용 → 민사(금지·손해배상) 대상, 무료 개인 앱에 적용되는지는 쟁점
- 제18조 제4항: (카)목 1)~3), (파)목은 형사처벌 대상에서 제외

## 4. 정보통신망법

- 제48조 제1항: 정당한 접근권한 없이 또는 허용된 접근권한을 넘은 침입 금지 (5년 이하 징역 또는 5천만원 이하 벌금)

## 7. robots.txt

https://fconline.nexon.com/robots.txt: Bingbot에 대해 /community/*, /news/*만 막음. /datacenter는 막혀 있지 않음. robots.txt는 법적 허가가 아니며, 판례상 "객관적으로 드러난 여러 사정" 중 하나로만 고려될 수 있음.

## 방법별 위험

| 위험 | A. 미리 수집해 배포 | B. 기기에서 직접 수집 |
|---|---|---|
| 저작권(DB권) | 높음: 개발자가 직접 대량 복제·배포 | 중간: 복제 주체는 사용자지만 개발자가 도구 제공 |
| 넥슨 약관 | 높음: 개발자가 직접 "유통" | 높음: 사용자 계정 제재 위험 |
| 정보통신망법·서버 부하 | 낮음 | 높음: 다수 기기 반복 요청, 차단 우회 시 접근권한 문제 |
| 앱스토어 (Apple 5.2.2 등) | 높음 | 높음 |

## 결정과 이후 방향

- 크롤링하지 않는다. 데이터는 NEXON Open API만 쓴다.
- 선수 정보 보강은 Open API의 랭커 선수 통계(`/fconline/v1/ranker-stats`)로 한다 (나중에 추가).
- 앱 이름·아이콘은 자체 디자인, 비공식 고지와 Open API 출처 표기 유지.
- 출시 전(8단계) 확인할 것: 선수 이미지·클래스 배지 사용이 Open API 약관 제6조 제3항의 게임 IP 활용 가이드 범위인지, Apple 5.2.1·5.2.2 관점에서 문제없는지.
